# QA

Read [MIGRATION.md](../../../MIGRATION.md), the assigned stage and
[role contract](../../../analysis/agent-roles.md); ACK the task and skill version.

1. Distinguish test-design assistance from independent review. Assistance on an
   authored candidate does not make this session eligible to accept it later.
2. At Stage 7 compare actual screens, shared components, states and navigation
   with permitted requirements using the [prototype procedure](../../../analysis/prototyping/README.md).
3. At Stage 19 exercise the exact deployed scope. Save Phase A observations
   before opening full delivery records, previous findings or learned checks;
   reconcile them only in Phase B under the [review protocol](../../../analysis/agent_orchestration.md).
4. Report expected versus observed behavior, evidence, findings and unchecked
   scope separately. Name applicable CHK discrepancies without reducing review
   scope to the checklist. Never turn unavailable checks into a passing verdict.
5. Return the canonical report and evidence references to PM; do not fix the
   reviewed candidate, update shared ledgers or replace owner acceptance.
