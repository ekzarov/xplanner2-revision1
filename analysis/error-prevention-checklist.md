## Active Checks

| Check | When applicable | Basis | How to check |
|---|---|---|---|
| CHK-001 Cited line numbers resolve to the cited file | Any stage record or review that cites a line number in a source, descriptor, JSP or other file as evidence | Self-detected Stage 1 error corrected before handoff: [`analysis/legacy_reconnaissance.md`](./legacy_reconnaissance.md#read-error-prevention); rule: [`analysis/legacy_user_flows_template_instructions.md`](./legacy_user_flows_template_instructions.md) (cite derived artifacts by symbol) | Take line numbers only from a per-file numbered read, never from a concatenated multi-file listing. Before handoff, check mechanically that every cited `file:line` exists in that file and that the line contains the cited element; any mismatch fails. |
| CHK-002 Permission conditions cite server-side enforcement | Any record, row or review that states a permission, role or access condition for an action, endpoint or channel | Stage 2 F-001 in [`analysis/reviews/stage-02-pass-001.md`](./reviews/stage-02-pass-001.md#read-f-001-server-side-permission-enforcement-is-missing-and-unrecorded), confirmed in [`analysis/stages/stage-01/stage-02-pass-001-dispositions.md`](./stages/stage-01/stage-02-pass-001-dispositions.md); constitution Principles III and XI | For each such claim, trace the handler from its mapping to the permission call. Record UI-only gating (hidden links, disabled controls) separately from server-side enforcement. Expected: the claim cites the server-side check, or states explicitly "no server-side check"; a not-authorized outcome is claimed only when a reachable code path raises it. |
| CHK-003 Claimed behavior is reachable from its entry point | Any record or review that attributes a side effect (history, e-mail, audit, persistence, outbound call), hook/injected-dependency behavior, rendering-path behavior or configuration setting/wiring to an entry point, channel, page or startup | Stage 2 F-002 in [`analysis/reviews/stage-02-pass-001.md`](./reviews/stage-02-pass-001.md#read-f-002-history-recording-is-overstated); author findings AF-01/AF-02 and dispositions in [`analysis/stages/stage-01/stage-02-pass-001-dispositions.md`](./stages/stage-01/stage-02-pass-001-dispositions.md); refined by pass 003 F-002 in [`analysis/stages/stage-01/stage-02-pass-003-dispositions.md`](./stages/stage-01/stage-02-pass-003-dispositions.md); constitution Principle III; refined by pass 004 F-003/F-004/F-006 in [`analysis/stages/stage-01/stage-02-pass-004-dispositions.md`](./stages/stage-01/stage-02-pass-004-dispositions.md) | Per entry point, channel and render path, confirm the writer, hook or outbound call is on the actual call path, overrides an invoked method, gets a non-null dependency, and that each cited setting reaches its consuming bean; list every loader of cited wiring files. Expected: each effect cites that path, else absent or `Inferred`. |
| CHK-004 Locale-dependent behavior compares every shipped variant | Any record or review that describes formats, messages or behavior derived from resource bundles, locales or other multi-variant configuration | Stage 2 F-003 in [`analysis/reviews/stage-02-pass-001.md`](./reviews/stage-02-pass-001.md#read-f-003-date-formats-differ-by-locale), confirmed in [`analysis/stages/stage-01/stage-02-pass-001-dispositions.md`](./stages/stage-01/stage-02-pass-001-dispositions.md) | Enumerate all shipped variants mechanically and compare the relevant key in each one. Expected: the record states the value per variant, or states that all variants agree; conclusions are never generalized from the default variant alone. |
| CHK-005 Every form validation key is covered | Any record or review that describes input validation of an editor form, import or other submitted form | Stage 2 pass 002 F-001 in [`analysis/reviews/stage-02-pass-002.md`](./reviews/stage-02-pass-002.md#read-f-001-time-entry-and-iteration-validation-rules-are-missing), confirmed in [`analysis/stages/stage-01/stage-02-pass-002-dispositions.md`](./stages/stage-01/stage-02-pass-002-dispositions.md); workbook alternative-path rule | List the message keys each form's validate method raises (bytecode constants or bundle keys). Expected: every key is covered by an alternative-path row citing the validator; fewer covered keys than raised keys fails. |
| CHK-006 Delete scenarios state the full data effect | Any record or review that describes deleting an object through any channel | Stage 2 pass 002 F-002 in [`analysis/reviews/stage-02-pass-002.md`](./reviews/stage-02-pass-002.md#read-f-002-delete-cascades-are-not-recorded), confirmed and extended in [`analysis/stages/stage-01/stage-02-pass-002-dispositions.md`](./stages/stage-01/stage-02-pass-002-dispositions.md) | Read the entity mappings and schema constraints for the deleted type. Expected: the row states cascaded children, uncascaded dependents and foreign-key outcomes, marked `Inferred` when only mappings are the evidence. |
| CHK-007 Figures match the current artifact after a correction | Any record revised after rows, statuses, counts or coverage change | Stage 2 pass 002 F-010 in [`analysis/reviews/stage-02-pass-002.md`](./reviews/stage-02-pass-002.md#read-f-010-reconnaissance-keeps-superseded-figures), confirmed in [`analysis/stages/stage-01/stage-02-pass-002-dispositions.md`](./stages/stage-01/stage-02-pass-002-dispositions.md) | Regenerate every count and percentage in the record from the current artifact, then search the record for the superseded values. Expected: no stale figure remains unless explicitly labelled historical. |
| CHK-008 Query property paths exist on the mapped entities | Any record or review that relies on an HQL, criteria or named query for a scenario, feed, report or API outcome | Stage 2 pass 003 F-001 in [`analysis/reviews/stage-02-pass-003.md`](./reviews/stage-02-pass-003.md#read-f-001-ical-and-soap-current-iteration-queries-use-unmapped-property-paths), confirmed and extended in [`analysis/stages/stage-01/stage-02-pass-003-dispositions.md`](./stages/stage-01/stage-02-pass-003-dispositions.md) | Resolve every alias and property path in the query against the mapped entity properties, not table columns. Expected: the outcome is recorded as working only when every path exists; otherwise the row states the expected failure, marked `Inferred`. |
| CHK-009 Credential values are never reproduced in records | Any record, review, evidence file, packet or script output written in this project that describes authentication, configuration, seed data or login behavior | Stage 2 pass 004 reviewer disclosure and owner decision `legacy-default-credential-classification:xplanner2-revision1` in [`analysis/reviews/evidence/S02-P004/pm-report-transcription.json`](./reviews/evidence/S02-P004/pm-report-transcription.json); [constitution amendment A3](../.specify/memory/constitution.md#read-a3-no-secrets-in-the-repository) | Cite the source location (file and line or symbol) and describe the behavior; never copy a password, key, token or login pair. Before handoff or publication, search the new material for credential values found in the sources. Expected: zero values; any hit is removed before publication or escalated to the owner. |
| CHK-010 Link targets are resolved with framework-added parameters | Any record or review that claims a link, redirect or navigation target lacks or mismatches a request parameter | Stage 2 pass 004 F-002 in [`analysis/reviews/stage-02-pass-004.md`](./reviews/stage-02-pass-004.md), confirmed in [`analysis/stages/stage-01/stage-02-pass-004-dispositions.md`](./stages/stage-01/stage-02-pass-004-dispositions.md) | Resolve the parameters the rendering tag, framework or forward adds (for example object ids, return targets, project context) before judging the link. Expected: a mismatch is recorded only when the resolved request still lacks the parameter. |
| CHK-011 Unauthenticated surfaces are enumerated mechanically | Any record or review of access control, public pages, shipped files or security findings | Stage 2 pass 004 F-001/F-005 in [`analysis/reviews/stage-02-pass-004.md`](./reviews/stage-02-pass-004.md), confirmed and extended in [`analysis/stages/stage-01/stage-02-pass-004-dispositions.md`](./stages/stage-01/stage-02-pass-004-dispositions.md) | List every mapping outside all authentication filters, every file shipped in or written to the public web root, and every public-page text in each bundle variant. Expected: each item is recorded with its exposure, or explicitly justified as harmless. |
| CHK-012 Request-derived values are traced to every sink | Any record or review that describes queries, page output, error or diagnostic pages, redirects or cookies fed by request parameters, headers, cookies or form fields | Stage 2 pass 005 F-002/F-003 in [`analysis/reviews/stage-02-pass-005.md`](./reviews/stage-02-pass-005.md), confirmed and extended in [`analysis/stages/stage-01/stage-02-pass-005-dispositions.md`](./stages/stage-01/stage-02-pass-005-dispositions.md) | For each request-derived value, follow it to its sinks: query text (bound or concatenated), HTML or script output (escaped or raw), error or diagnostic echo, and cookies (lifetime, flags). Expected: each unsafe sink is recorded with its location and exposure; safe sinks state why. |
